# Mimir Metals: Digital Toolroom 

An industrial-grade inventory management and operational dashboard designed for high-speed manufacturing environments. 

Built to eliminate the lean wastes of excess motion and waiting, this tool bridges the gap between the shop floor and the front office by tracking die stacks across multiple stations (Alpha, Bravo, Charlie, etc.) in real-time.

## ⚙️ Core Features
* **Operational Analytics Hub:** Top-level metrics giving plant managers a quick-glance view of total capital assets, tools in repair, and scrapped dies.
* **Smart Filtering:** Natural language parsing allows operators to find specific tools instantly (e.g., typing "3/8 repair" automatically filters the inventory without nested dropdowns).
* **Frictionless "Receive" Workflow:** Optimistic UI updates ensure operators aren't blocked by slow shop Wi-Fi when logging returned tools.
* **Simulated AI Vision OCR:** Demonstrates the elimination of manual data entry by extracting tolerances from paperwork photos.

## 🛠️ Technical Implementation
* **Frontend:** React, TypeScript, Vite
* **Demo Architecture:** Live, frictionless portfolio demo utilizing a `localStorage` DB stub to allow prospective clients to interact with the data without hitting login walls or live databases.
* **UI/UX:** "Dark Industrial" theme with high-contrast UI elements designed specifically for readability on rugged tablets under poor shop lighting.
